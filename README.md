# HAMZA // The Living Network

An interactive cyber-security portfolio for Muhammad Hamza, a BSc (Hons) Cyber Security student at Nottingham Trent University.

## Live portfolio

[Open the GitHub Pages site](https://muhammadhamza291098-hub.github.io/POTFOLIO/)

## Featured work

- AI-Assisted Threat Intelligence Dashboard
- Fault-Tolerant UDP Load Balancer
- PCAP Parser & Anomaly Lab
- Multi-Tenant Takeaway Voice Agent
- Infrastructure & Security Home Lab
- Offline Smart Home Automation System
- Ransomware Incident & ISMS Analysis

The portfolio separates submitted project figures from representative reconstructions and includes project context, role, evidence, tools and feedback in DEEP mode.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000/POTFOLIO/`.

## Deployment

Every push to `main` runs the GitHub Actions workflow in `.github/workflows/deploy-pages.yml`, builds a static Next.js export and deploys it to GitHub Pages.
